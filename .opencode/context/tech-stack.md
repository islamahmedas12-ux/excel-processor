# Tech Stack

## Backend
- Python 3.x
- Flask
- openpyxl (Excel reading/writing)
- xlrd (legacy .xls support)
- flask-cors

## Frontend
- React 18
- Vite
- TypeScript
- Tailwind CSS

## Infrastructure
- Stateless processing (no DB, no file storage)
- All files processed in-memory
- LibreOffice headless for PDF export (planned)
