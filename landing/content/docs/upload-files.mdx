# Upload Files

## Upload an Excel File

**POST** `/api/v1/files/upload`

Upload an `.xlsx` or `.xls` file. Returns a `file_id` used in all subsequent operations.

```bash
curl -X POST http://localhost:5000/api/v1/files/upload \
  -H "Authorization: Bearer <token>" \
  -F "file=@/path/to/workbook.xlsx"
```

**Response**

```json
{
  "file_id": "abc123",
  "filename": "workbook.xlsx",
  "size_bytes": 204800,
  "sheets": ["Sheet1", "Sheet2"],
  "message": "File uploaded successfully"
}
```

---

## List Files

**GET** `/api/v1/files`

Returns all files you have uploaded.

```json
{
  "files": [
    {
      "file_id": "abc123",
      "filename": "workbook.xlsx",
      "size_bytes": 204800,
      "uploaded_at": "2026-01-15T10:30:00Z",
      "sheets": ["Sheet1", "Sheet2"]
    }
  ]
}
```

---

## Delete a File

**DELETE** `/api/v1/files/<file_id>`

Permanently deletes the file.

```json
{ "message": "File deleted" }
```

---

## Storage Usage

**GET** `/api/v1/storage/usage`

Returns your current storage consumption and plan limits.

```json
{
  "file_count": 2,
  "total_bytes": 409600,
  "plan": "free",
  "limits": {
    "max_files": 3,
    "max_file_mb": 100,
    "storage_gb": 0.3
  }
}
```

---

## Plan Limits

| Plan     | Files | Max per file | Total storage |
|----------|-------|-------------|---------------|
| Free     | 3     | 100 MB      | 300 MB        |
| Basic    | 50    | 500 MB      | 5 GB          |
| Pro      | 200   | 1 GB        | 20 GB         |
| Business | 999   | 2 GB        | 100 GB        |

When you exceed a limit, the API returns:

```json
{ "error": "plan_limit:files:3" }
```
